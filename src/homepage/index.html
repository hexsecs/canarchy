CANarchy is an open, stream-first runtime for analyzing and manipulating CAN and J1939 buses. Every command emits a canonical JSONL event. Every event is replayable. Nothing is hidden behind a GUI, a license key, or a dongle.

WHAT THIS IS

A toolkit for security researchers, red teams,
fleet auditors, OSS tinkerers, and the
occasional agent operating without supervision.

WHAT IT IS NOT

A replacement for can-utils, python-can,
SavvyCAN, or common sense.

STREAM

JSONL events. Stable schema. Pipe to grep, jq, duckdb, or your agent. The CLI is the API.

NO.02● STABLE

J1939

Heavy vehicles are not an afterthought. PGNs, TP reassembly, address claim — first-class.

NO.03● STABLE

UDS

Discover services. Trace transactions. Every active command is gated behind --ack-active, --dry-run, and a typed YES.

NO.04● STABLE

DBC

Provider-backed discovery. Local cache. Reverse-engineering matchers when you only have frames.

NO.05● STABLE

GATEWAY

Bridge buses. Rewrite frames in flight. Replay captures with real timing or compressed.

NO.06● STABLE

AGENT

Deterministic subcommands. MCP server. Build loops with Claude, Cursor, or anything that can shell out.
